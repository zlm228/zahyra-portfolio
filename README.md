# Zahyra Otero — Portfolio

Personal portfolio for Zahyra Otero, an NYU Data Science student interested in product, AI, and thoughtful technology.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Project content lives in `app/page.tsx`, with the visual system and responsive styles in `app/globals.css`. Static assets—including the résumé and social-sharing image—live in `public/`.
